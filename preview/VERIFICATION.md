# 初版验收记录

日期：2026-11-18。使用本地 HTTP 预览和浏览器视口模拟检查，未进行手机真机测试。

## 已验证

- JavaScript 语法：`npm run check` 通过。
- 桌面 1440 × 900、手机横屏 844 × 390、手机竖屏 390 × 844 的页面效果。
- 四张官方背景均可加载，多次自动切换正常，人物图在宽屏保留顶部。
- 设置中暂停背景后，跨越切换周期仍保持原图；恢复轮播、手动换图与关闭镜头运动可操作。
- 游客、微信、QQ 三个入口先显示连接状态，再显示对应方式的欢迎弹窗。
- 连接中关闭后再次点击可重新启动模拟登录；关闭的连接不会被旧定时任务重新打开。
- 公告、关于、用户协议、隐私说明均可打开关闭，关闭后焦点返回原入口。
- 全屏按钮可以进入、退出全屏。
- 首图 404 时跳到第二张；全部背景 404 时显示渐变兜底，公告等按钮仍可操作。
- 临时模拟减少动态效果偏好时，镜头开关关闭且不可启用，背景淡入时长为 0ms。系统偏好的 CSS 分支另经静态检查。
- 最终正常预览的浏览器错误与警告日志为空。

失败素材与减少动态效果测试使用临时独立 HTTP 服务，没有修改正式页面或图片。临时验收服务不属于交付运行环境。
