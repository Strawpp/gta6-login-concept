# 七张美术与切图优化验收记录（0.3.0）

- 保留 6000ms 切换周期及 105% 放大；淡入从 1200ms 缩短至 600ms。先解码并挂载下一张图片，切图时旧图保持不透明，新图单独淡入。

- 六项可控时钟测试通过：预解码与固定周期；快速选图响应最后一次请求；弹窗、后台、镜头开关冻结并恢复；WebP/JPEG 及全部失败；减少动态效果；只剩一张可用图时，缩放结束后开关弹窗不会重新缩放。
- 浏览器故障页确认 WebP 404 时使用 1600px JPEG，设置缩略图仍正常；全部背景 404 时显示渐变，公告和微信模拟登录可用。
- 微信、QQ、游客入口可到达欢迎弹窗；关闭和 Esc 后焦点返回原入口。公告阅读后红点消失。
- 1440 × 900 桌面、844 × 390 横屏、390 × 844 竖屏、320 × 568 小屏布局检查通过，按钮和适龄装饰位于视口内；小屏滚动到最后一张缩略图时，关闭按钮仍固定可见且可点击。桌面加载 1600px 资源，手机加载 1280px 资源。
- 浏览器全屏可进入、退出；关于弹窗显示 0.3.0 与适龄装饰说明，正常页面浏览器错误和警告日志为空。
- `npm run check`、`npm test`、`git diff --check` 通过。来源见 `assets/SOURCES.md`；新版截图为 `login-v6-*.jpg`。
